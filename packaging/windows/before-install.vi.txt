TISA BOT Setup: bộ cài này làm những gì

TISA BOT là phần mềm mã nguồn mở (giấy phép MIT):
https://github.com/tieusangstudio-hash/tisa-bot

NHỮNG THAY ĐỔI TRÊN MÁY NÀY

1. Tải mã nguồn TISA BOT từ GitHub về thư mục "TISABot" trong thư mục người dùng của bạn. Ghi chú, trí nhớ và cài đặt của bạn cũng nằm trong thư mục đó.

2. Cài Git, Python và Node.js nếu máy chưa có (qua winget, hoặc tải từ git-scm.com, python.org và nodejs.org). Windows có thể hỏi quyền một lần.

3. Cài các thư viện Python mà TISA BOT cần, ngay trong thư mục TISABot.

4. Nếu giữ dấu tích ở trang kế tiếp: cài bốn công cụ AI dòng lệnh từ chính hãng của chúng: Claude Code (Anthropic), Codex (OpenAI), Antigravity CLI (Google) và Grok Build (xAI). Đây là sản phẩm riêng, có giấy phép và chính sách quyền riêng tư riêng. Không cài thì TISA BOT vẫn chạy được bằng API key.

5. Nếu giữ dấu tích ở trang kế tiếp: TISA BOT tự chạy khi bạn đăng nhập Windows.

6. Thêm TISA BOT vào Start menu và, nếu tích chọn, ra Desktop.

QUYỀN RIÊNG TƯ

TISA BOT chạy trên chính máy của bạn. Không theo dõi, không gửi số liệu sử dụng. TISA BOT không chuyển thông tin sang hệ thống khác trên mạng trừ khi bạn yêu cầu. Ví dụ: nhà cung cấp AI bạn chọn sẽ nhận những tin nhắn bạn gửi cho nó, và một kết nối bạn thêm vào (Telegram, Zalo, Google...) sẽ trao đổi dữ liệu với dịch vụ đó.

Tự nó, TISA BOT chỉ tải các file công khai từ GitHub và PyPI để xem có bản cập nhật hay không, và giữ các công cụ AI dòng lệnh ở bản mới qua trình cập nhật của chính hãng.

Bản đầy đủ (tiếng Anh): https://github.com/tieusangstudio-hash/tisa-bot/blob/main/PRIVACY.md

GỠ CÀI ĐẶT

Windows Settings, Apps, "TISA BOT", Uninstall. Thư mục TISABot (ghi chú, trí nhớ, cài đặt) được giữ lại cho đến khi bạn tự xoá. Git, Python và Node.js là chương trình riêng: nếu không cần nữa thì gỡ trong cùng danh sách Apps.
