# Conversion Structure Principles

> Structure the page to convert, not just to look good. A pretty page that buries the offer converts worse than a plain page built on these principles.

## The 5-Second Above-Fold Test

Within 5 seconds of landing, the visitor must be able to answer:
1. **What is this?** (product/service in plain words)
2. **Who is it for?** (they recognize themselves)
3. **What do I get?** (the outcome/benefit)
4. **What do I do next?** (one obvious action)

If any answer isn't visible above the fold, fix the hero first. This beats any visual polish.

## Message-Match

The page's headline must match the promise of the traffic source.
- Ad says "50% off launch price" → hero says "50% off launch price", not a generic tagline.
- Email teased a "free spa trial" → the page leads with the free trial.
Mismatch = bounce. Always ask the traffic source (Clarification Gate captures it) and mirror its promise.

## CTA Hierarchy

- **One primary action** per page. Everything else is secondary and visually quieter.
- Repeat the primary CTA at natural decision points (after hero, after proof, after pricing, at the end) — same action, not competing ones.
- Make the CTA contextual and specific: "Book my free trial", not "Submit".
- Primary CTA color = the palette's CTA/accent, high contrast against its surroundings.

## Friction Ladder

Each section should remove one barrier between "interested" and "acting":
1. Hero → clarity (what/who/benefit/action)
2. Problem/agitation → "they get me"
3. Solution → "this fixes it"
4. Proof → "it works for people like me" (place proof beside the claim)
5. Offer/pricing → "the value is worth it" (anchor value vs price)
6. Risk-reversal → "I can't lose" (guarantee)
7. Urgency → "act now" (genuine scarcity/deadline)
8. Final CTA → the easy yes

Drop any step the offer doesn't need — don't pad. Low-ticket pages can collapse to hero → proof → CTA.

## Proof Placement

Do not dump all testimonials at the bottom. Put each proof element **next to the claim it backs**:
- Claim "get results fast" → a result-speed testimonial right there.
- Claim "trusted by many" → logos/numbers near the trust statement.

## Mobile-First (Vietnam reality)

Most VN traffic is mobile. Design for the phone first:
- Single-column flow, thumb-reachable CTAs, 44x44px tap targets.
- 16px+ body text, generous line height.
- Fast load (inline critical styles, compressed images).
- Sticky primary CTA on mobile is often worth it.

## Voice-of-Customer Tie-In

When VoC data exists (from `/ts-chan-dung-khach-hang` or the Second Brain file `01-ho-so/03-khach-hang-muc-tieu.md`), use the customer's **exact words** in the headline, pains, and objections. Real customer language is both higher-converting and a strong anti-AI-slop signal — it reads human because it *is* human.

## Quick Structure Picker

- **Simple/low-ticket offer** → Hero → 3 benefits → proof → CTA
- **High-trust needed (health/legal/high-ticket)** → Hero → problem → solution → heavy proof → guarantee → CTA
- **Transformation offer** → Hero → before/after → mechanism → proof → CTA
- **Lead capture** → benefit hero → preview of value → short form (≤3 fields) → CTA

Pair the picker with the Layout Variation Matrix so structure stays conversion-sound while the visual layout varies.
